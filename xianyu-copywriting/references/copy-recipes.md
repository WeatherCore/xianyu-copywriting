# 文案配方库

## 开头句式库（第一人称，五选一或混搭）

- **数字锚点型**：「15 页 136 条，我自己实验课一篇篇敲出来的 Nmap 笔记」
- **踩坑型**：「这份笔记里的坑我基本都替你踩过了——Wireshark 过滤器配错一次就白抓一晚上」
- **痛点场景型**：「网安实验课要交报告的那周，我把整套扫描流程从头到尾做了一遍，顺手把过程全记了下来」
- **身份代入型**：「如果你也是这学期刚开始学 Kali，看不懂扫描结果里那堆 open/filtered/closed，这份笔记正好」
- **反向坦诚型**：「先说清楚：这不是什么神仙资料，就是一个普通学生把实验课内容整理扎实了，胜在每一步都能照着跑通」

开头一句话内必须出现：品类词 + 一个具体数字或具体场景。禁止用「干货满满」「超全整理」开头。

## 三种正文结构配方

### 配方 A：故事型（适合有真实效果背书）
我为什么做它（真实经历 2-3 句）→ 结果一句话 → 里面有什么（清单带数字）→ 适合谁 → 局限与声明 → 交付

### 配方 B：清单型（适合内容驱动，目录即卖点）
一句话开场 → 内容清单（分组，每组一句话 + 一个亮点，总共 4-6 组）→ 适合谁 → 局限与声明 → 交付
这是默认配方；用户旧文案多半是它的「未压缩版」——8 个以上分组平铺就是信号。

### 配方 C：问答型（适合小白向资料，预演买家疑问）
开头场景 → 自问自答买家最可能问的 3 个问题（能直接跑吗 / 要基础吗 / 能复现吗）→ 适合谁 → 声明 → 交付

三条配式的收尾固定结构：
1. 合规/局限声明（一句）
2. 交付行：「拍下后发电子版 [格式]，不是实物哦～秒发。」
3. 同学感结尾（可选但强烈推荐）：「看完有不明白的可以问我，看到就回。」——这一句是「同学感」的关键，商家不会说这句。

## 标题配方

结构：`[品类词] + [核心主题] + [最有说服力的一个数字/限定]`，≤30 字。

- 品类词放最前：笔记 / 复习提纲 / 题解 / 模板 / 实验报告 / 面经
- 最多一个竖线「｜」，不用【】★🔥 等符号堆砌
- 限定词要具体：「可复现」「带报文拆解」「15 页 136 条」好于「全套」「完整版」「多种原理」
- 好：「Nmap 网络扫描实战笔记｜主机发现 端口扫描 抓包分析 可复现」
- 差：「【超全】Nmap 全套笔记★从入门到精通★网安必备」

## 关键词配方

- 10-15 个，全部是买家真的会打进搜索框的词
- 三类混着来：
  - 精确词：工具名、课程名、章节名（Nmap、Wireshark 抓包、三大 TCP 扫描）
  - 场景词：网安实验、端口扫描、信息搜集、期末复习
  - 人群词：学生党笔记、网安入门、计算机专业
- 同一个词的多个变体只保留一个（#TCP 扫描 / #TCP 三种扫描 / #TCP 扫描模式 → 留一个）
- 放文末一行，`#` 开头空格分隔；关键词不要塞进正文句子

## 交付行固定写法

「拍下后发电子版双 PDF 全套笔记，不是实物哦～秒发。」
——一句话说完格式 + 非实物 + 时效。「无延迟直接获取」「秒发无延迟」这类同义堆叠删掉。
