# 闲鱼学生自产学习资料文案

## Goal
把用户手里的自产学习资料，写成一篇读起来像「学长学姐在班群里安利笔记」的闲鱼文案：真实、具体、可信，能出单但不喊麦。

## 核心语气（一句话）
同学之间的安利，不是商家的详情页。叙述者是资料作者本人，用第一人称「我」。

## Workflow
1. **收集素材**：用户给了什么先用什么。缺关键信息（覆盖范围、页数/条目数、格式、适合谁、真实效果背书）时，用 `references/product-types.md` 的追问模板**一次性问完 3-5 个**，不挤牙膏、不瞎编细节。
2. **提取卖点**：对素材跑一遍「卖点挖掘十问」，挖出的是事实——数字、覆盖范围、踩坑记录、可复现性。卖点必须是事实，不是形容词。
3. **选品类切入**：按四类（课程笔记 / 考试冲刺 / 求职材料 / 项目实战）确定买家真实痛点与开头场景。
4. **生成文案**：按 `references/copy-recipes.md` 的结构配方产出完整五件套。
5. **自检**：过一遍下方 Validation 清单与黑词库，不合格就改。
6. **输出**：按「文案五件套」格式交付，结尾附 1-2 条发布小贴士（价格锚点、擦亮时间、首图建议）。

## 文案五件套（标准输出）
1. **标题**：≤30 字，品类词开头 + 核心搜索词，最多一个竖线，不堆符号。
2. **首行钩子**：一句话，用具体数字或场景勾住对应人群。
3. **正文**：我为什么做它（1-2 句）→ 里面有什么（清单化、带数字）→ 适合谁（点名处境）→ 小声明（局限/合规）→ 交付说明（电子版、秒发、非实物）。
4. **关键词标签**：10-15 个买家真的会打的搜索词，`#` 格式放文末。
5. **发布小贴士**：可选，视用户需要给。

## Decision Tree
- 素材齐全 → 直接走 Workflow 2-6
- 素材只有一句话（如"高数笔记"）→ 先追问关键信息，拿到再写
- 用户给旧文案要改 → 先按黑词库诊断油腻点，**保留其中的真实事实**，再重构
- 商品涉嫌盗版转卖、代写代做、账号买卖 → 拒绝并说明平台风险，不出方案
- 敏感品类（安全工具、真题回忆、模板直接照搬）→ 必须嵌合规声明，模板见 `references/pitfalls-and-words.md`
- 需要参考真实改写效果 → 读 `references/sample-annotated-copy.md`

## 语气红线（不可违反）
- 卖点用事实与数字；"超全""绝绝子""天花板"这类空洞形容一律不写
- 感叹号全文 ≤2 个，emoji ≤3 个或不用
- 主动交代至少一条局限（页数不多、只覆盖某章、需要基础）——可信度来自坦诚
- 不跪求、不造稀缺（"仅剩 X 份""错过后悔"）
- 不出现站外引流词（+V、威信、私聊看主页），闲鱼会限流
- 允许口语和不完美，读起来像发在班群里的话，不像详情页

## Validation（交付前自检）
- [ ] 黑词库零命中（`references/pitfalls-and-words.md`）
- [ ] ≥3 个具体数字/事实
- [ ] ≥1 处主动交代局限或使用前提
- [ ] 标题含品类词，正文自然出现 ≥5 个买家会搜的词
- [ ] 交付方式（电子版/秒发/非实物）写明
- [ ] 朗读测试：像同学安利，不像商家喊麦
