1.【前置基础・Docker底层认知扫清盲区】

- 沙盒隔离机制完整讲解：容器互相隔离，无性能损耗、跨系统兼容特性
- 容器VS虚拟机核心对比：分层架构图解、启动速度、资源占用、部署效率差异
- Docker完整工作架构：Dockerfile→镜像→本地容器→Docker Hub推拉全流程拆解
- 两大底层核心技术：Namespace（进程/网络/文件系统隔离）、Cgroup（CPU/内存资源配额限制）
- UnionFS联合文件系统原理：镜像分层读写机制、底层bootfs/rootfs区分
- Docker适用场景与局限性：只负责计算，数据需外部挂载持久化

3.【镜像全套操作命令大全（可直接复制）】
- 帮助类：docker version / docker info / docker --help
- 镜像检索：docker search 解读星级、官方镜像标识区分
- 拉取镜像：docker pull 指定版本/latest最新镜像、第三方源拉取方式
- 本地查看：docker images 列表字段（仓库名/标签/ID/大小）解读
- 镜像管理：docker tag重命名、docker rmi单/批量删除镜像

4.【容器全套核心命令+两种运行模式区分】
- 容器启动核心参数详解：-d后台、-it交互、-p端口映射、-v数据挂载、--name命名
- 前台交互容器：run -it 退出即销毁使用场景
- 后台守护容器：run -d 长期服务部署专用，exec无侵入进入容器
- 容器生命周期：start/stop/restart/kill启停、rm删除运行/停止容器
- 容器查看：docker ps（运行中）、docker ps -a（全部容器）
- 容器运维：docker logs查看日志、docker top查看内部进程
- 文件互传：docker cp 容器与宿主机双向拷贝实操
- 退出技巧：exit关闭容器 / Ctrl+P+Q后台留存容器

7.【容器数据卷持久化详解】

- 三种挂载模式实操：
  ①指定路径绑定挂载：宿主机目录<=>容器目录双向同步
  ②匿名挂载：自动生成宿主机长路径卷

- 挂载权限控制：ro只读 / rw读写参数用法
